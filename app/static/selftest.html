What this runs

Fixed review sentences in English and Chinese, with typos, follow-ups that depend on the previous answer, "cut the size in half", and injection or "place it for me" attempts. Each goes through the same in-process chat the first screen uses, and through the intent router on its own. A row passes when the chat lands on the gold intent written beside it in eval/selftest_prompts.jsonl before the first run. Injection and order requests must end in the refusal (gold: help).

The sentences were written by an agent that had already read the router's code, so a pass here is not a blind score. The first run is frozen below with its misses; later runs do not replace it.
